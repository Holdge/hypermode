HyperMode Privacy Policy / 隐私政策

Updated: 2026-10-12. Publisher: Holdge. Contact: holdgewong@gmail.com.

Local data / 本机数据 HyperMode stores workspaces, folders, favorites, conversation history, selected attachments and optional screenshot previews in your browser extension storage. It does not use browser account sync storage. The publisher operates no analytics or conversation collection server and does not sell user data.

AI services / AI 服务 You choose and configure an AI service. When you submit a question, your question, relevant conversation messages and the context or attachments you selected are sent to that service. Images are compressed; text, PDF and Word documents are parsed locally. Connection validation sends your API key to the selected service with a model-list request. External AI website handoff fills your question and selected text context into the website. Automatic sending can be disabled. Each provider handles requests under its own privacy policy. The extension does not include a publisher-provided AI account or API key.

Credentials / 密钥 API keys remain in the current browser session by default. If you explicitly enable remembering a key, the extension stores it locally. This storage is not a separate encrypted credential vault. A key saved for one API endpoint is not automatically reused at another endpoint.

Browser access / 浏览器权限 Tab titles, URLs and loading state are used to display, search and manage browser instances. Optional history access enables browser-history search after permission is granted. Optional page preview access captures only visible ordinary web pages already in the workspace; it excludes incognito and browser-internal pages. Screenshot previews are local and capped at 80 images, seven days and approximately 5 MB. Disabling previews clears the screenshot cache. Optional website access is used for the selected AI endpoint and page previews. External AI scripts operate on supported AI websites for input handoff.

Optional local tools / 可选本机工具 An optional local companion manages workspaces through CLI / MCP and imports Arc workspace directory metadata on macOS. It does not import passwords or cookies. Its authenticated communication is restricted to the local machine.

Control and deletion / 控制与删除 You can remove your API key through AI settings, disable optional features and revoke browser permissions. Conversations can be moved to trash; version 2.0.0 does not provide a permanent-empty-trash control. Uninstalling the extension normally removes its browser extension storage. Export data you need before uninstalling. Exported backups and optional companion files remain under your control and must be deleted separately. Data already sent to an AI provider is subject to that provider's retention and deletion process.

Limited use / 使用限制 The use and transfer of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide user-facing workspace, search and AI features. It is not used for advertising, sold to data brokers, or used by the publisher to train generalized AI models.

Contact / 联系 For privacy questions, contact holdgewong@gmail.com. Do not include API keys, passwords, private conversations or confidential files in a public support issue.
